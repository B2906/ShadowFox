# 📖 Project Highlights

### 🤖 Task-1: AI Keyboard Assistant
- Built an intelligent next-word prediction system.
- Implemented an LSTM-based deep learning model.
- Developed an interactive Streamlit application.

### 🚗 Task-2: Car Price Prediction
- Performed data preprocessing and feature engineering.
- Trained multiple regression models.
- Compared model performance using evaluation metrics.
- Deployed the final model using Flask.

### 🧠 Task-3: GPT-2 Language Model Analysis
- Implemented the GPT-2 language model using Hugging Face Transformers.
- Explored tokenization, encoding, and text generation.
- Conducted experiments on contextual understanding and prompt engineering.
- Evaluated the effects of Temperature, Top-k, and Top-p sampling.
- Visualized experimental observations.
- Discussed ethical considerations, limitations, and future improvements of large language models.
